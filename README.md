# StockForge AI

Open-source, Android-first digital asset production automation platform.

## Status

Early development — Core CLI v0.1 foundation.

## Quick start

```bash
uv sync
uv run stockforge version
uv run stockforge doctor
uv run stockforge init
uv run stockforge project create demo
uv run stockforge project list
```

The CLI is designed for Termux/Linux first. Heavy AI workloads will be integrated through plugins/adapters later; the core remains lightweight.
