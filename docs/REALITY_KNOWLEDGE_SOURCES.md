# Reality Knowledge Source Register

Date: 2026-08-20

## Technical sources used for Construction v1

- Leica Geosystems DISTO guidance and 3D Disto manual: laser measurement requires meaningful targets and supports room geometry measurements.
- Hilti PS 300 / PS 1000 and operating guidance: concrete scanning is used for rebar/object localization and cover/depth assessment; scanning requires the sensor/tool to interact with the concrete surface.
- Tramex MEX5/ME5 and building survey kits: building moisture inspection uses moisture meters across drywall and other building materials, with different measurement/probe modes.
- FLIR building inspection guidance and MR277: thermal imaging assists building diagnostics and should be used as part of an inspection workflow rather than treated as the sole proof of moisture.

## Evidence hierarchy

Manufacturer/professional sources define technical truth. Training/professional organizations provide workflow context. Marketplace research defines commercial patterns, search language, and gaps only. Internal generation audits define observed model failure modes.
